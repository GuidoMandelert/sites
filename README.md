# Guido's personal website

## Add your profile photo

1. Put your photo in the `images` folder.
2. Name the file exactly `guido.jpg`.
3. Refresh the website.

The website automatically replaces its initials placeholder when `images/guido.jpg` is available. You do not need to change any code.

## Preview locally

Open `index.html` in a web browser. For live updates while editing, open this folder in VS Code and use the Live Server extension.

## Easy text edits

All page text is in `index.html`. The contact placeholder near the bottom can be replaced with your own email or profile link whenever you are ready.
